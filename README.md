# Permainan Ular Tangga (Modern Snake & Ladder Game)

Aplikasi permainan Ular Tangga berbasis Python dengan antarmuka grafis (GUI) Tkinter modern dan dilengkapi dengan Unit Test otomatis.

## Fitur
- **2 Pemain**: Mendukung permainan 2 pemain (Pemain 1 & Pemain 2) secara bergantian.
- **GUI Interaktif**: Tampilan papan permainan, animasi dadu, dan indikator giliran pemain.
- **Mekanik Ular & Tangga**: Tangga untuk naik dan ular yang memindahkan pemain ke posisi bawah.
- **Riwayat Pemenang**: Riwayat pemenang tersimpan otomatis pada file `riwayat_ular_tangga.txt`.
- **Unit Testing**: Pengujian otomatis logika permainan menggunakan modul `unittest` sebelum game dimulai.

## Cara Menjalankan

Pastikan Python 3 sudah terinstal di sistem Anda.

Jalankan perintah berikut:
```bash
python game_ular_tangga.py
```
